# TucTuc Tel-U

A campus transport booking app for Telkom University students: sign in with your student ID, pick a route, and book a ride.

**Live:** [trans-tuc-tuc.vercel.app](https://trans-tuc-tuc.vercel.app)

The app is registered for copyright (HaKI) as *Aplikasi Trans TucTuc*.

## Stack

- Front end: HTML, CSS, vanilla JavaScript (`index.html`, `styles.css`, `app.js`)
- Back end: Node.js + Express (`server.js`), with a JSON file store (`database.js`, `data.json`) and bcrypt-hashed passwords
- Hosting: Vercel (`vercel.json`)

## Run locally

```bash
npm install
npm start
# open http://localhost:3000
```
